# KDSS 官网全面改版（2026-11-01）

## 已定
- 风格：浅色企业风（白底、深蓝主色、大量留白、浅灰卡片），参考 NetApp / IBM / 华为企业存储官网的稳重感。
- 生产规模：只写取整的概数，不写集群名、IP、客户名。
- 发布：本地完成 → 截图给用户确认 → 推 GitHub 分支 → 用户确认后再替换 210.245.153.28 上的线上版本（旧版备份保留）。

## 技术方案
- 仍是纯静态 HTML/CSS/JS，不引入构建工具（nginx 直接托管，和现在一样）。
- 去掉 Google Fonts（大陆访问慢或失败），改系统字体栈：中文苹方/微软雅黑，西文 Inter 风格的系统无衬线。
- 一套新的设计规范（颜色、字号、间距、卡片、按钮、表格、代码块），所有页面共用一个 `css/site.css`；旧的 4 个 CSS 与粒子画布动画删除。
- 插图全部重画为细线 SVG（架构、数据流、EC 条带、部署拓扑），统一配色。
- 中英双语保持现有路径（`/` 英文、`/zh/` 中文），链接不变，避免外链失效。
- 响应式：桌面 / 平板 / 手机三档；无横向滚动。
